# Changelog

## 0.1.0

- Token spend panel: periods (24 h, 7 days, 30 days, all time), models, projects, dollar equivalent at API prices.
- Day breakdown by model and project; calendar coloured by project; click a project to filter everything.
- `/tokens` command; panel language follows Claude Code's `language` setting, then the system locale (English or Russian).
- A project is named after the folder its session was opened in.
